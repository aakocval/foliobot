FolioBot demo

This page loads the widget and the answer engine, then feeds them profile.example.json. Open the chat button in the corner and ask about the example person's projects, tech stack, or contact details.

Edit examples/profile.example.json and reload to see the answers change.

This page loads its profile with fetch, which browsers block on file://. Serve the repository over HTTP instead: run python3 -m http.server in the repo folder and open http://localhost:8000/examples/demo.html.
